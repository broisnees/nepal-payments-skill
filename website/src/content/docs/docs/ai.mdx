## Markdown for any page

Add `.md` to a page's path to get it as plain Markdown, for example [`/docs/providers/esewa.md`](/docs/providers/esewa.md) for the eSewa integration guide. The **Settings** menu in the header has the same actions for the page you're on:

- **Copy page as Markdown** puts the page on your clipboard, ready to paste into a chat.
- **View as Markdown** opens the raw page.
- **Open in ChatGPT** and **Open in Claude** start a chat that reads the page.

## Prefer the skill for coding

For writing the integration itself, [install the skill](/docs/install/) instead. The agent then reads the same references on demand, plus the tested adapters it copies into your project.
