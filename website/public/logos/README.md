# Gateway logos

Official logos of the Nepali payment gateways, taken from each gateway's own published files on 2026-11-05.
The marks belong to their owners. Use them only to show that a gateway is supported, unaltered (eSewa's
guidelines forbid changing colours or proportions), and keep the site's "not affiliated" notice.

| File | Gateway | Source |
|---|---|---|
| `esewa.svg` | eSewa, for light backgrounds | Vector, cropped from eSewa's logo guidelines (https://cdn.esewa.com.np/ui/notice/Logo_Guidelines.pdf), page 2 |
| `esewa-white.svg` | eSewa, for dark backgrounds | Same PDF, page 3 |
| `khalti.svg` | Khalti | Vector, from the header of https://docs.khalti.com/ |
| `khalti-by-ime.png` | Khalti by IME (also covers IME Pay after the merger) | https://khalti.com/ |
| `fonepay.png`, `fonepay-white.png` | Fonepay, light and dark | https://fonepay.com/downloads |
| `connectips.png` | connectIPS (NCHL) | https://connectips.com/ (only a 100x65 file is published) |
| `nps.png`, `nps-white.png` | Nepal Payment Solution (NPX brand), resized to 1200 px wide | https://nepalpayment.com/ |
| `cybersource.png` | CyberSource, a Visa solution | https://www.cybersource.com/ |

Only eSewa and Khalti publish vector logos; the others are their official PNGs, not traced copies.
